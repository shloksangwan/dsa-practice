## How this repo is organised

```
leetcode/     one file per problem, named <number>-<slug>.<ext>
codeforces/   one file per problem, named <contest><index>-<slug>.<ext>
```

Every solution starts with a short header: the problem link, the idea in one or two lines,
and the time and space complexity.
